


## Methodolog

It is closer to:

"Reverse-engineer a suitable application specification from the security capabilities of the tools in our CI/CD security pipeline."

In other words, you first ask:

What security vulnerabilities can our pipeline tools detect?

Then:

What kind of application features/code would allow us to intentionally introduce those vulnerabilities?

Then:

What specification should FinSec have so that we can demonstrate the pipeline detecting them?
